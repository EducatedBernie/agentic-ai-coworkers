**Coach:** ### Quick Python Coding Drill

Implement:

```python
def top_k_recommendations(scores: dict[str, float], k: int) -> list[str]:
    ...
```

Requirements:

- Return the restaurant IDs with the highest scores.
- Return at most `k` IDs.
- Break score ties alphabetically by restaurant ID.
- Do not mutate the input dictionary.
- Raise `ValueError` if `k < 0`.

Example:

```python
scores = {"r3": 0.9, "r1": 0.9, "r2": 0.8}

top_k_recommendations(scores, 2)
# ["r1", "r3"]
```

Explain the time and space complexity.

**You:** ```python
import heapq

def top_k_recommendations(scores: dict[str, float], k: int) -> list[str]:
    if k < 0:
        raise ValueError("k must be non-negative")
    return [rid for rid, _ in heapq.nsmallest(k, scores.items(), key=lambda kv: (-kv[1], kv[0]))]
```
nsmallest with key (-score, id) gives highest score first and breaks ties alphabetically. It does not mutate the dict. Time is O(n log k) because it keeps a heap of size k, space is O(k). If k >= n it just sorts, so O(n log n).

Your implementation is correct and handles validation, tie-breaking, and non-mutation cleanly. Complexity analysis was accurate, including the `k >= n` case.
